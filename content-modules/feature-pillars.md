# LandingCritic — Feature pillars

## Core engine
- Blunt 5-point critique: value prop, CTA, target user, proof, pricing
- Score out of 5 so weak spots are obvious
- Names the single highest-priority fix

## Workflow & output
- Indie founders get an honest page read without a copywriter
- Checklist feedback keeps the founder's voice
- Copy-ready guidance to apply, not a ghostwritten rewrite

## Trust & control
- Decision-support for landing copy — not conversion guarantees
- No fabricated conversion-rate claims
- Demo mode without a live API key
